# 梗捕手

一个可直接打开的网络热梗搜索小程序原型。

## 使用方式

双击 `run.bat`，或直接在浏览器里打开 `index.html`。

## 已有功能

- 输入关键词即时搜索热梗库
- 按短视频、社交平台、游戏圈、影视综艺、生活表达筛选
- 按热度、更新时间、名称排序
- 查看热梗含义、出处线索、常见说法和例句
- 一键跳转到百度、微博、B站、小红书、抖音做实时搜索
- 收藏热梗，收藏状态会保存在本机浏览器

## 说明

前端静态页面不能稳定直接抓取各大平台内容，因为多数平台会限制跨域请求或要求登录。当前版本采用“本地热梗库 + 平台实时搜索入口”的方式，保证打开即用。后续如果要做成真正实时聚合版，可以再加一个后端服务去接热榜 API、RSS 或爬虫任务。
